# Can You Hear It? — pastel interface demo

Copy `run_game.py` and the contents of `game/` into the project root on your game branch. Merge folders, keeping your existing `game/sentences.py` and `game/__init__.py`. This package does not change `src/` or the assignment notebook.

From the project root, run:

```sh
python run_game.py
```

Open http://127.0.0.1:8765/web/ if the browser does not open automatically. Python 3.9+ and a modern browser are sufficient. No pip installation required. Stop with Ctrl+C. If port 8765 is busy, stop the earlier game server first.

## Included

- Welcome, username, gameplay, results and leaderboard screens, in English.
- Responsive lavender, sage, sky blue, peach and rose palette.
- Five original MP3s supplied by the project owner, with expected transcripts based on their filenames. Speech speed and voice settings were not independently verified.
- Levels: Legend / Champion / Pro / Skilled / Beginner / Rookie.
- Channels: 1 / 2 / 4 / 8 / 16 / 32. Scores: 100 / 90 / 80 / 70 / 60 / 50.
- Two playback starts per level, one submitted nonempty answer per level. Listen before submitting. Failed playback does not consume a listen.
- Correct answers finish the sentence. Wrong answers or More channels advance one level. Final failure/skip gives zero. New sentences restart at Legend.
- Case, punctuation and extra spaces are ignored. Words must otherwise match. No spelling tolerance yet.
- Score saved once at the completion of a round. Repeat usernames allowed. Equal scores share competition ranks (1, 1, 3).

## Demo audio and scores

All levels currently play the SAME ORIGINAL audio. They do not simulate channel changes. The interface prominently labels this as demo mode. Demo scores use the localStorage key `listening-game-demo-v1`; they are not scientific performance measurements. Scores remain in this browser for this host/port. Clearing browser data removes them. No shared online leaderboard, authentication or anti-cheat system is provided.

Reloading loses an unfinished game. Previously completed games remain. Public use with unfamiliar players is preferable because the five sentences can be memorized.

## Connecting the pipeline later

`game/web/app.js`: `audioPath(sentence, channels)` is the playback integration point. Export 30 reconstructed WAV files (five sentences × six channel counts) from the Python pipeline. For example, `game/assets/processed/sentence_01_ch_1.wav`. Update `audioPath` to select the matching file, verify that all variants exist and work, and then replace the demo labels and use a NEW score key. Do not remove demo labels while still using the original audio.

The browser decodes the original MP3s directly for this interface preview. Preprocessing and resampling belong to the Python pipeline that exports the processed files, not this preview player.

`game/web/model.js` holds the game rules. `style.css` holds the palette and responsive layout. `index.html` is the page shell. `app.js` connects rendering, playback and browser persistence.

## Audio provenance

Generated by the project owner using https://www.text-to-speech.online/ and supplied for this prototype. Preserve the service/voice/rate details in project documentation when known. This package does not establish redistribution rights for third-party synthesized voices.

## Celebration update
Correct answers show a full celebration screen with pastel confetti, an ear coin and the earned points. Continue manually using Next sentence. Reduced-motion preferences disable the confetti and coin animation. After failing/skipping Rookie, Listen to original allows replay without awarding points. Demo audio is still identical at every level. The original playback path is separate from the future processed audio path. `game/web/coin.svg` is a replaceable vector placeholder, not a reconstruction of a supplied coin image.
